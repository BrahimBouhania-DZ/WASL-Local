# متطلبات LinkDesk Local

## منجز
- ربط آمن بالرمز
- نقل ملفات بدون حد للحجم مع فحص الامتداد
- نصوص وروابط
- حافظة مع إذن
- مشاركة شاشة
- عربي/فرنسي/إنجليزي + RTL/LTR
- وضع فاتح/داكن/تلقائي + تخصيص
- واجهة احترافية

## غير منجز / قيود
- WebRTC بين أجهزة عبر WebSocket إشارات يحتاج تحسين
- نقل حقيقي بين جهازين عبر جلسة
- تشفير إضافي
- HTTPS محلي
