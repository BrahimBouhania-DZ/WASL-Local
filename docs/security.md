# أمن التطبيق - LinkDesk Local

## مبادئ الأمان
- يعمل محليًا فقط داخل الشبكة المحلية
- لا يرسل بيانات خارجية
- رموز اقتران آمنة

## ضوابط منفذة
- توليد رموز بـ `crypto.randomInt` (CSPRNG)
- صلاحية الرمز 120 ثانية + استهلاك مرة واحدة
- تحديد محاولات التحقق + حظر مؤقت
- تنظيف الجلسات المنتهية تلقائياً
- التحقق من المدخلات بـ Zod
- Rate limiting على الاقتران ورفع الملفات
- فحص Origin لـ WebSocket وCORS
- فحص امتداد الملفات + حظر الملفات التنفيذية
- منع اجتياز المسارات
- أسماء ملفات آمنة بـ UUID
- فحص `../` في مسارات التحميل

## حدود
- HTTP (يفضل استخدام localhost/شبكة موثوقة)
- WebRTC يعتمد على سياق آمن
- لا يوجد تشفير طرف للطرف مخصص بعد
