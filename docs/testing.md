# اختبار التطبيق - LinkDesk Local

## تشغيل يدوي
```bash
npm run dev
```
- عميل: http://localhost:5173
- خادم: http://localhost:8080

## سيناريوهات اختبار
1. إنشاء رمز اقتران ورؤيته
2. التحقق برمز صحيح
3. التحقق برمز خاطئ / مستخدم / منتهي
4. عرض الأجهزة المتصلة
5. رفع ملف مسموح
6. محاولة رفع ملف محظور (.exe)
7. مشاركة الشاشة
8. قراءة/كتابة الحافظة
9. تغيير اللغة والوضع

## فحص سريع
```bash
curl http://localhost:8080/health
curl http://localhost:8080/info
```
