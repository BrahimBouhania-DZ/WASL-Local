# LinkDesk Local

تطبيق محلي لربط الهاتف بالحاسوب داخل الشبكة المحلية.

## المميزات
- ربط آمن بين الأجهزة
- نقل الملفات في الاتجاهين
- إرسال النصوص والروابط
- مشاركة الحافظة
- مشاركة الشاشة عبر WebRTC
- دعم العربية والفرنسية والإنجليزية
- وضع فاتح/داكن مع تخصيص

## التشغيل
```bash
npm install
npm run dev
```

- الخادم: http://localhost:8080
- العميل: http://localhost:5173

## المتطلبات
- Node.js 22+
- متصفح حديث
